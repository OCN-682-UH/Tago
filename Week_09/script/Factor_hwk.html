Introduction

This homework report will focus on utilizing the factor function. Using the rocky intertidal data along the US Pacific Coast (Starfish Point to Scripps), the goal of this homework is to:

  1. String clean the data
  2. Make a plot where at least one axis is a factor in a meaningful order.

I have two questions that the plot should look at:

  1. Observe the distribution of the small barnacle (% cover) across the different tide zones (Low > Mid > High) in order.
  2. Observe the average small barnacle abundance across all sites

Clean the Data Using {janitor}

The janitor function allows for quick data cleaning, making it ready for data analysis or visualization. In this code chunk, we want to use this function to clean the messy and dirty data. We are going to clean names by using the clean_names ().

#cleans the names that we couldnt clean with the previous function
# ".x and [1.]"  acts as the placeholder for the columns that are being processed targeting the number 1 and the period
#str_to_title: standardizes the lowercase strings, fixes messy casing and capitalization
#str_squish: cleans up the messy spaces
#str_remove_all: removes any instance of those speciic texts, characters, pattern or punctuation 
#after the cleaning process, we convert the quadrat into factor = levels to make it meaningful for tide heights: Low > Mid > High 

intertidal_clean <- intertidal_name |>
  mutate(across(quadrat, ~str_to_title(str_squish(str_remove_all(.x, "[1.]"))))) |>
  mutate(quadrat = factor(quadrat, levels = c("Low","Mid","High")))

Figure 1 shows that the small barnacles are mostly found during the high tides across all sites. High tide is ecologically important for these barnacles, because they are safe from predators, and there is no competition for space. In the low tide zones, the small barnacles have low distribution because there is more predatory accessibility and there are more organisms competing for space.

Figure 2 shows an interesting geographical trend where small barnacle abundance are highly observed in Starfish Point the northern intertidal site, and at Shell Beach and Dana Point the southern intertidal site. These are all data collected during the high tide zones, highlighting that small barnacles favor these site due to high influxes of waves from the open ocean carrying tiny barnacle larvaes allowing them to thrive in these areas. In addition, Dana Point has dense mussel beds that provides protection for the small barnacles, while Starfish Point has the predators that favor mussel more than small barnacles.
