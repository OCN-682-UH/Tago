Introduction

This report will cover what we have learned in class: developing our own functions. The primary purpose of creating functions is to automate repetitive tasks-such as cleaning multiple dataframes, using the same plot to observe the correlations, or to simply run your script- while minimizing copy-paste errors when duplicating the code chunks. It will also help the data be organized, readable and reusable.

To see whether the functions are successful, it should follow the four-part anatomy:

  1. Function name - describes what the function does (choose a good descriptive name)
  2. Arguments - the input slot that lists the multiple arguments
  3. Function body - places code inside the {} (curly curly blocks) to execute the task
  4. Return Statement - the final output sent back to reader or viewer

In this report we will use the penguins dataset to develop the two useful functions, but will test its flexibility using the water quality data from Sydney (download from tidy tuesday). The objectives are:

  1. Creating a summary table that identifies and excludes the outliers, along with making it publication-quality ready table
  2. Create a visual boxplot ~ lets visualize the data distribution and compare groups.

Objective 1: Create a Summary Table

This is a very important portion with regards to cleaned data prior to making the boxplot. Instead of repetitively trying to create clean summary tables, we can use this function to generate cleaner tables for any dataframe that is being prepped for boxplot.

show code 
#generate the clean summary table with kable to make it cleaner 

clean_table <- function(data, group, value, type = "html", custom_cols = NULL) { if(is.null(custom_cols)) {
      group_name <- str_to_title(gsub("_", "", deparse(substitute(group)))) 
      custom_cols <- c(group_name, "Sample Size","Mean",
                       "Median", "Max")
    }
  data |>
  filter(!is.na({{value}}), !is.na({{group}})) |>
  group_by({{group}})|>
  summarize( sample = n(),
             mean = mean({{value}}),
             median = median({{value}}),
             max = max ({{value}}),
             .groups = "drop") |>
  arrange(desc(mean)) |>
  kbl(align = "c", digits = 2) |>
  kable_styling(
    bootstrap_options = c("striped","hover","condensed"),
    full_width = FALSE, position = "center") |>
  row_spec(0, bold = TRUE, color = "aliceblue", background = "#2D3748")
}

Objective 2: Create Boxplot

The idea for this function was to make sure everything is included, the theme, the filtering, the colors. This was to make sure my life would be super super easy, since I plan to use this function alot for my projects.

show code 
box_color <- function(data, group, value, colors_vec, n, type) {
  data |>
    filter(!is.na({{ group }}), !is.na({{ value }})) |>
    ggplot(aes(x = factor({{ group}}), y = {{ value }}, fill = factor({{ group}}))) +
    geom_boxplot(alpha = 0.8, outlier.color = "#e74c3c") +
    scale_fill_manual(values = pnw_palette(name = colors_vec, n = n, type = type)) +
    theme_minimal(base_size = 14) +
    theme(plot.title = element_text(face = "bold", 
                                  size = 14),
        axis.text.x = element_text(face = "plain"),
        axis.text.y = element_text(face = "plain"),
        axis.line = element_line(color = "black",
                                 linewidth = 0.6),
        axis.title.x = element_text(face = "bold"),
        axis.title.y = element_text(face = "bold"),
        panel.grid.major.x = element_blank(),
        panel.grid.minor.x = element_blank(),
        panel.grid.major.y = element_blank(),
        panel.grid.minor.y = element_blank())
}

scatter_color<- function(data, value_x, value_y, group, colors_vec, n, type) {
  data |>
    filter(!is.na({{ value_x }}), !is.na({{ value_y }}), !is.na({{ group }}), {{value_x}} < 40) |> 
    ggplot(aes(x = {{ value_x}}, y = {{ value_y}}, color = factor({{ group}}))) + #changed fill to color so data can be colored 
    geom_point(alpha = 0.2, size = 1.2) + #changed to correlation plot
    geom_smooth(
      method = "lm", 
      aes(group = 1), #find one correlation across all data
      color = "#2D3748", 
      linewidth = 1.2, 
      se = TRUE) +
    scale_color_manual(values = pnw_palette(name = colors_vec, n = n, type = type)) + #changed the fill to scale color to match point 
    theme_minimal(base_size = 14) +
    theme(plot.title = element_text(face = "bold", 
                                  size = 14),
        axis.text.x = element_text(face = "plain"),
        axis.text.y = element_text(face = "plain"),
        axis.line = element_line(color = "black",
                                 linewidth = 0.6),
        axis.title.x = element_text(face = "bold"),

        panel.grid.major.x = element_blank(),
        panel.grid.minor.x = element_blank(),
